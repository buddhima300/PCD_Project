## Getting Started

The frontend now connects to the Node.js backend. Start PostgreSQL and run `npm run dev` inside `backend/`, then run `npm run dev` from this repository root and open http://localhost:5173. Sign in with your actual backend account; demo shortcuts and browser-persisted login identities are removed.

The original frontend screens use the PostgreSQL-backed operations API with their existing data contracts. See [backend setup](backend/README.md) and [original dataset import, workflow persistence and login mappings](docs/backend/06-original-workflows.md).

1. Run `npm install`
2. Run `npm run dev`
