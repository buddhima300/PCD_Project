# Shared reference theme

The latest Formix reference replaces the earlier supervisor-only treatments: nearly black canvas, white sentence-case headings, burnt-orange actions, subtle outlined cards, cinematic orange-lit equipment illustrations and Inter typography with restrained weight variation. The font is a visual approximation; a raster reference does not establish an exact font family. Operational status colors retain their semantic meanings through dark-surface tokens.

The theme is applied at `html.agency-theme` and maintained in `src/agency-theme.css`. All supervisor, permanent employee, freelancer and login pages, dialogs, loading states and notifications inherit the shared tokens. The login page now has a desktop introduction/form layout, collapses to one column on small screens, and uses the supplied PortCity Digital logo. The obsolete login light/dark toggle and unrelated decorative logo were removed. Hub links use cinematic artwork and clear icon/action placement; KPI cards use tone-aware surfaces. No business rules, APIs or permissions change. Equipment artwork is stored locally in `public/images/equipment-ember-illustrations.png`; route-specific inline positions keep each illustration assigned to its intended card.

Changed files: `src/index.css`, `src/agency-theme.css`, `index.html`, `src/App.tsx`, `src/components/layout/AppShell.tsx`, `src/pages/Login.tsx`. The superseded supervisor-only stylesheet was removed. Browser coverage includes responsive widths of 375, 768, 1024 and 1440 pixels, every legacy navigation destination for each role, branding, hub navigation, browser history and mobile focus handling.

Fonts use the existing Google Fonts delivery convention with local sans-serif fallbacks. Screenshots are saved in `test-results/supervisor-theme-equipment.png` and `test-results/supervisor-theme-dashboard.png` by the theme browser test. Production build passed; the existing main-bundle size warning remains.
